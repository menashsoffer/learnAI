# בונים עם AI — סדנה לצוערים לשלטון המקומי

אתר-מצגת שמלווה הרצאה חיה. **המסך הוא עוגן, לא מסמך** — המנחה מדבר, המסך מציג כותרת
ומילות מפתח בלבד. ההסברים המלאים יושבים בשני מקומות שלא מוקרנים לקהל:
מגירת ההנחיה של המנחה, ומסכי המשתתפים.

## הרצה

```bash
npm install
npm run dev
```

| פקודה                    | מה היא עושה                                 |
| :----------------------- | :------------------------------------------ |
| `npm run dev`            | שרת פיתוח                                   |
| `npm run build`          | בנייה לאתר (`dist/`)                        |
| `npm test`               | בדיקות                                      |
| `npm run typecheck`      | בדיקת טיפוסים                               |
| `npm run lint`           | בדיקת סגנון                                 |
| `npm run validate:decks` | ולידציה למבנה הדק + שמירה על יציבות ה-slugs |

בנייה לקובץ HTML יחיד לצפייה אופליין:

```bash
VITE_TARGET=singlefile DECK_ID=ai-cadets-2026 npx vite build --config vite.config.singlefile.ts
```

## שלוש כניסות

מסך הפתיחה (`#/d/ai-cadets-2026`) מציע שתי דלתות, ויש גם כניסה שלישית ישירה:

| נתיב                        | למי                                                                                     |
| :-------------------------- | :-------------------------------------------------------------------------------------- |
| `#/d/:deckId/present/:slug` | **מנחה** — מגירת מה להגיד, טיימר, הצצה לסצנה הבאה. מוגן בקוד רך (`meta.presenterCode`). |
| `#/d/:deckId/study/:slug`   | **משתתפים** — רק הסצנות שיש להן `student`: הוראות פעילות, פרומפטים להעתקה, חומר עיון.   |
| `#/d/:deckId/:slug`         | צפייה רגילה — קישור לשיתוף אחרי ההרצאה.                                                 |

## עריכת תוכן

כל התוכן יושב ב-`content/decks/ai-cadets-2026/deck.json`. אין HTML — כל סצנה מורכבת
מבלוקים מוצהרים (`paragraph`, `list`, `callout`, `columns`, `example-prompt`, `heading`, `cta`).

לכל סצנה יש ארבעה שדות תוכן, ולכל אחד קהל אחר:

| שדה               | מי רואה                   | הכלל                                            |
| :---------------- | :------------------------ | :---------------------------------------------- |
| `data`            | **הקהל, על המסך הגדול**   | מינימלי. כותרת + עוגן קצר. אף פעם לא פסקת הסבר. |
| `notes`           | המנחה בלבד (`N` + המגירה) | מה לעשות: שאלות לקהל, הדגמות, תזמון.            |
| `presenterScript` | המנחה בלבד (המגירה)       | מה להגיד — כולל הבדיחות.                        |
| `student`         | המשתתפים במכשיר שלהם      | ההסבר המלא, חומר עיון והפרומפטים להעתקה.        |

סצנה עם `student` נכנסת אוטומטית לדק המשתתפים; בלעדיו — היא סצנת מנחה בלבד.

### הוספת טיפוס סצנה

תיקייה תחת `src/scenes/<type>/` עם `defineScene({ type, schema, Component, defaultData })`,
ושורה אחת ב-`src/scenes/index.ts`. הטיפוסים הקיימים: `hero`, `content-skill`, `workshop-instructions`.

### יציבות קישורים

`scripts/released-slugs.json` שומר על ה-slugs שכבר פורסמו. שינוי slug מחייב רשומה
ב-`meta.redirects`, אחרת `npm run validate:decks` נכשל.

## פרסום

האתר מתפרסם ל-GitHub Pages בכתובת <https://menashsoffer.github.io/learnAI/> על ידי
`.github/workflows/deploy.yml`, שרץ על כל דחיפה ל-`master`.

⚠️ **דרוש שינוי הגדרה חד-פעמי בגיטהאב:** Settings → Pages → Build and deployment →
Source = **GitHub Actions**. עד שזה ייעשה, גיטהאב ממשיך להגיש את שורש הריפו כמו שהוא —
כלומר את `index.html` הלא-בנוי, שה-script שלו מצביע על `/src/main.tsx`. דפדפן לא יודע
להריץ TSX, ולכן הדף החי יוצא ריק לגמרי.

מכיוון שזהו אתר פרויקט (ולא אתר משתמש), `base` מוגדר ל-`/learnAI/` ב-`vite.config.ts`.
הבנייה האופליין דורסת אותו ל-`./` כי היא נפתחת מ-`file://`.

### קבצים לקריאת מכונה

`public/` מכיל את מה שסוכנים וזחלנים קוראים: `robots.txt`, `sitemap.xml`, `llms.txt`
(כולל סעיף «מתי להשתמש»), `404.html`, ועמודי `about` / `contact` / `privacy`.
התוכן הסטטי שבתוך `#root` ב-`index.html` הוא מה שנקרא בלי JavaScript — React מחליף אותו
בטעינה. `src/seo/publicFiles.test.ts` מאמת את כולם.

## לוגו

שני הלוגואים — צוערים לשלטון המקומי ומשרד הפנים — יושבים ב-`src/assets/brand/`.
כל אחד בשתי גרסאות: AVIF (קטן) עם נפילה ל-PNG, כי מחשב ישן באולם עלול לא לתמוך ב-AVIF,
ולוגו חסר על המקרן זה לא משהו שמתקנים באמצע הרצאה. הדפדפן מוריד רק אחד מהם.

סמל הצוערים מופיע בפינת הסרגל העליון בכל שקף; שניהם יחד בראש מסך הפתיחה.
