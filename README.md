# אתר-מצגת אינטראקטיבי: בינה מלאכותית לצוערים לשלטון המקומי

אתר-מצגת אינטראקטיבי ומלא להרצאת בינה מלאכותית לצוערים לשלטון המקומי (10.09.2026).  
האתר נבנה בקובץ `index.html` יחיד ללא תלויות חיצוניות ברשת, ומתאים לצפייה בו-זמנית על **מסך טלוויזיה גדול** באולם ועל **מכשירים אישיים** (לפטופ/טאבלט/סמארטפון) של המשתתפים.

---

## 🚀 איך פותחים ומציגים?

1. **פתיחה מהירה**:
   - פשוט פתחו את הקובץ `index.html` בכל דפדפן מודרני (Chrome, Edge, Safari, Firefox).
   - אין צורך בהתקנה, בשלבי Build, או בשרת מקומי.
   - האתר פועל ב-100% אופליין (למעט קישור יציאה לכלי AI חיצוני בסצנה 16-17 בלבד).

2. **הקרנה באולם**:
   - על מסך הטלוויזיה/המקרן הראשי: פתחו את `index.html` ולחצו על **`F`** למסך מלא.
   - הצוערים גולשים בנפרד במכשיר האישי שלהם דרך אותו הקישור.

---

## ⌨️ מפת קיצורי מקלדת ומחוות

| מקש / ג׳סטה | פעולה |
| :--- | :--- |
| **חץ שמאלה / Space / PageDown** | מעבר לסצנה הבאה |
| **חץ ימינה / PageUp** | חזרה לסצנה הקודמת |
| **Esc** | פתיחת/סגירת **תצוגת רשת (Grid Overview)** של 23 הסצנות לקפיצה מהירה |
| **N** | פתיחת/סגירת **הערות למנחה (Presenter Cues)** סודיות לכל סצנה |
| **F** | מעבר/יציאה ממצב **מסך מלא (Fullscreen)** |
| **Swipe ימינה/שמאלה** | ניווט במכשירי מגע (טאבלטים/סמארטפונים) |

---

## ✍️ איך עורכים את התוכן והמשחקים?

כל 23 הסצנות, הטקסטים והמשחקים מרוכזים במבנה נתונים יחיד בראש הקובץ `index.html`:

```javascript
const SCENES = [
  {
    id: 1,
    act: "מערכה 0 — פתיחה",
    type: "hero",
    title: "כותרת הסצנה",
    subtitle: "תת-כותרת",
    notes: "הערות מנחה שמופיעות בלחיצה על N",
    selfReading: "טקסט מפורט למצב קריאה עצמית"
  },
  ...
];
```

* כדי לערוך את שאלות המשחקים בסצנות 10 ו-21 — עורכים את השדות `quote`, `options`, ו-`explanation` בסצנה המתאימה במערך `SCENES`.
* כדי לשנות את משך טיימר הדיפולטי בסצנה 17 — משנים את `defaultSeconds` (ברירת המחדל: 600 שניות = 10 דקות).

2. **תוכן משחקים סופי**: מומש מבנה משחקים פעיל ומלא בסצנות 10 ו-21. במידה ויהיו דוגמאות טקסט עירוניות נוספות, ניתן להחליפן בקלות במערך `SCENES`.
3. **טיימר תרגול חי**: ברירת מחדל של 10 דקות בסצנה 17 (ניתן לכיול עם לחצני +-1 דקה בזמן אמת).
