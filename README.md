# בונים עם AI — סדנה לצוערים לשלטון המקומי

כלי להרצאה חיה בת 90 דקות. **המסך הוא עוגן, לא מסמך** — המנחה מדבר ומדגים בכלי האמיתי,
המסך מחזיק כותרת ועוגן קצר, וההסברים המלאים יושבים בשני מקומות שלא מוקרנים לקהל: מגירת
ההנחיה של המנחה, והמכשירים של המשתתפים.

המסלול: מקרה מוניציפלי אחד שכל משתתף בוחר בפתיחה, וארבעה תוצרים עליו — פרומפט, מסמך מובנה,
מצגת החלטה, ועמוד אינטראקטיבי לתושבים.

## הרצה

```bash
npm install
```

```bash
npm run dev
```

| פקודה                    | מה היא עושה                                     |
| :----------------------- | :---------------------------------------------- |
| `npm run dev`            | שרת פיתוח                                       |
| `npm run build`          | בנייה לאתר (`dist/`)                            |
| `npm run verify`         | כל מה ש-CI מריץ                                 |
| `npm test`               | בדיקות                                          |
| `npm run validate:decks` | ולידציה למבנה הדק + שמירה על יציבות ה-slugs     |
| `npm run run-sheet`      | מייצר מחדש את `documentation/RUN-SHEET.md` מהדק |

## שלוש כניסות

| נתיב                        | למי                                                                        |
| :-------------------------- | :------------------------------------------------------------------------- |
| `#/d/:deckId/present/:slug` | **מנחה** — מסך קדם-טיסה, שני שעונים, סחיפה מול התוכנית, נקודות בקרה, דילוג |
| `#/d/:deckId/study/:slug`   | **משתתפים** — סרגל שלב, ״מה עושים עכשיו״, פרומפטים להעתקה                  |
| `#/d/:deckId/:slug`         | צפייה רגילה — קישור לשיתוף אחרי ההרצאה                                     |

כניסת המנחה מוגנת בקוד רך (`meta.presenterCode`) — לא אבטחה, רק כדי שמשתתפים לא ייכנסו
בטעות למה-להגיד.

## מצב מנחה

הדק יודע כמה זמן כל שלב אמור לקחת, ולכן יכול להגיד לכם איפה אתם עומדים:

- **מסך קדם-טיסה** לפני שלב 1 — רשימת ההכנה, כל 13 השלבים עם הדקות שלהם, וקוד QR
  שהמשתתפים סורקים כדי להיכנס למסך שלהם. ״התחל הרצאה״ מפעיל את השעון.
- **שני שעונים** — כמה זמן ההרצאה רצה מול כמה הייתה אמורה, וכמה נשאר לתרגיל הנוכחי.
- **סחיפה** — ״3′ מאחור״ / ״2′ מקדימה״, בדקות שלמות.
- **נקודת בקרה** — ההוראה מדף הריצה מופיעה על השלב שאליו היא שייכת, בזמן שעוד אפשר לפעול.
- **החזרת זמן** — כשיש חריגה, המערכת אומרת על איזה שלב רשות לדלג כדי לחזור לזמן.

## עריכת תוכן

כל התוכן ב-`content/decks/ai-cadets-2026/deck.json`. אין HTML — כל סצנה מורכבת מבלוקים
מוצהרים. לכל סצנה ארבעה שדות תוכן, ולכל אחד קהל אחר:

| שדה               | מי רואה                 | הכלל                                            |
| :---------------- | :---------------------- | :---------------------------------------------- |
| `data`            | **הקהל, על המסך הגדול** | מינימלי. כותרת + עוגן קצר. אף פעם לא פסקת הסבר. |
| `notes`           | המנחה בלבד              | מה לעשות: שאלות לקהל, הדגמות, תזמון             |
| `presenterScript` | המנחה בלבד              | מה להגיד                                        |
| `student`         | המשתתפים במכשיר שלהם    | ההסבר המלא והפרומפטים להעתקה                    |

ולכל סצנה גם תקציב זמן: `budgetMin`, ואופציונלית `optional` ו-`controlPoint`.
אחרי שינוי תקציב — `npm run run-sheet`.

### סצנת תרגול

מסך תרגול חייב ארבע שכבות, והסכימה אוכפת את זה:

```jsonc
{
  "doNow": "משפט ציווי אחד — הדבר הראשון והגדול ביותר על המסך",
  "steps": ["עד חמישה צעדים", "לכולם"],
  "prompt": { "mode": "copy", "label": "...", "text": "..." }, // הרצפה
  "successCriteria": ["איך יודעים שסיימתם"],
  "stuck": [/* רשת ביטחון */],
  "extension": [/* "סיימתם מוקדם?" */],
}
```

`mode: "build"` מחליף את הרצפה בטופס ארבעה שדות שמתחבר לפרומפט מוכן — לשימוש רק במקום
שבו התבנית נלמדת.
